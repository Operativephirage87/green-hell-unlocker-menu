## 🧩 About

**Green Hell catalog Menu** is a curated list of Green Hell open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource tracker, status HUD
- **Quality-of-Life Helpers** — crafting catalog, map notes, overlay notes
- **Research Notes** — survival layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Survival Helpers
- Resource Tracker — keep an eye on nearby materials
- Status HUD — monitor hydration, nutrition, and sanity values
- Map Notes — review explored areas and landmarks
- Time Control Notes — adjust day/night pacing for study (0.1x to 5x)

### 🎨 Catalog & Building
- Crafting Catalog — browse recipes, tools, and structures
- Building Notes — organize base layouts and construction plans
- Storage Tracker — improved inventory visibility

### 🏋️ Practice Layout
- Exploration Notes — segment study on any region
- Movement Notes — practice traversal and climbing routes
- Camp Setup Notes — chain shelter and fire setups in the editor
